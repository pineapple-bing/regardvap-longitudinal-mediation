# 3. Longitudinal mediation analysis

The primary clinical analysis estimates the total effect (TE), interventional
direct effect (IDE), and interventional indirect effect (IIE) of baseline
carbapenem resistance on 60-day mortality through daily appropriate active
treatment (`M0`--`M3`).

The complete executable v3 core is
`01_run_regardvap_longitudinal_mediation_v3_no_wgs.R`.
It creates Table 3 (counterfactual risks and effect decomposition), Table 4
(prespecified sensitivity analyses), and Figure 4 (TE decomposition).

Simulated WGS variables and WGS analyses are absent from this pipeline.
