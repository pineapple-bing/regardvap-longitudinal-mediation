# 2. Longitudinal trajectories

This section describes the Day 0--3 observation process and does not estimate
a causal effect. It generates:

- Figure 1: measurement timeline;
- Figure 2: longitudinal DAG;
- Table 2: daily severity, microbiology-information, and appropriate-treatment summaries;
- Figure 3: observed trajectories; and
- supporting trajectory-distribution tables.

Within-day ordering is `L_t, O_t` measured before the day-t treatment decision
`M_t`; mortality is assessed at Day 60.
