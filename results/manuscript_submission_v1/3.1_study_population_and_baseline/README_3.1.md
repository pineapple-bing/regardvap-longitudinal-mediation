# 3.1 Study population and baseline characteristics

## Primary presentation table

- `table1_complete_verified.csv`: complete baseline/onset Table 1 for all 460 eligible participants with recorded baseline exposure (`A`) and 60-day outcome. Columns are Overall, non-resistant (`A=0`, n=319), recorded carbapenem-resistant (`A=1`, n=141), and the absolute standardized difference.
- `table1_complete_verified.html`: formatted rendition of the same aggregate table.
- `table1_cohort_audit.csv`: the population and group-count audit used by the complete table.

The complete table is generated by [`01_study_population_and_baseline/R/02_complete_baseline_table.R`](../../../01_study_population_and_baseline/R/02_complete_baseline_table.R). It deliberately excludes 3GCR subgroup labels, WGS variables, plasmid variables, and any other unvalidated categories. No participant-level data are included here.

## Earlier pipeline outputs

- `table1_baseline_summary.csv`: earlier compact table from the longitudinal pipeline.
- `diagnostic_cohort_flow.csv`: earlier cohort-flow diagnostic.
- The participant-level symptom-day versus Day 0 treatment audit is generated in `_scratch` and intentionally excluded from manuscript-facing outputs.
