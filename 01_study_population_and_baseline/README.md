# 1. Study population and baseline characteristics

This section produces the source-data audit, daily eligibility/censoring checks,
cohort flow, and baseline Table 1 by baseline carbapenem-resistance status.

The clinical population is defined before model fitting. The `A=0` group must
not be labelled “carbapenem susceptible” while culture-negative episodes remain
eligible.

Outputs generated by the master runner include `table1_baseline_summary.csv`,
the patient-level analytic dataset, and data-quality tables.
